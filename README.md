# (ICMP Traceroute + WHOIS)

Консольная утилита на Python для трассировки маршрута передачи данных к заданному узлу.

Программа отправляет эхо-запросы ICMP (Echo Request) с последовательно увеличивающимся значением TTL (Time to Live) и анализирует ответы от промежуточных маршрутизаторов (Time Exceeded) и целевого хоста (Echo Reply). Для каждого белого IP-адреса выполняется рекурсивный запрос по протоколу WHOIS для извлечения названия провайдера, номера автономной системы (ASN) и страны.

---

## Основные возможности

- Полностью кастомная сборка сетевых пакетов и ручной расчёт интернет-контрольной суммы (RFC 1071).
- Извлечение сетевой информации через WHOIS-серверы (IANA, RIPE и др.).
- Динамическое управление параметрами трассировки (таймауты, размер пакета, интервалы).
- Автоматическое определение локальных/приватных IP-адресов (RFC 1918) для исключения лишних WHOIS-запросов.

## Архитектура проекта

```
my_tracert/
├── main.py              # Точка входа, парсинг аргументов командной строки
└── tracer/              # Пакет с бизнес-логикой утилиты
    ├── __init__.py      # Инициализатор пакета
    ├── icmp.py          # Класс ICMPPacket (упаковка, расчёт чексуммы, валидация ответов)
    ├── network.py       # Классы IPUtils (серые IP) и WhoisClient (TCP-клиент для WHOIS, регулярные выражения)
    └── core.py          # Класс Tracer (управление raw-сокетом, логика хопов, select)
```

## Требования к окружению

- **ОС:** Linux (тестировалось на Fedora / Ubuntu) или macOS.
- **Python:** версии 3.8 или выше.
- **Права:** root / sudo (необходимы для открытия сырых сокетов `socket.SOCK_RAW`).

## Установка и запуск

Клонируйте репозиторий и перейдите в директорию проекта:

```bash
git clone 
cd my_tracert
```

Запуск осуществляется через `main.py`. Просмотреть доступные флаги:

```bash
python3 main.py --help
```

---

## Параметры командной строки

| Аргумент | Флаг | По умолчанию | Описание |
|---|---|---|---|
| `address` | — | обязательный | Целевой домен или IP-адрес |
| `--max-ttl` | `-m` | `30` | Максимальное число шагов / TTL |
| `--timeout` | `-t` | `3` | Время ожидания ответа (в секундах) |
| `--attempts` | `-n` | `3` | Количество запросов на каждый шаг |
| `--interval` | `-i` | `1` | Пауза между повторными запросами (в секундах) |
| `--size` | `-s` | `40` | Общий размер ICMP-пакета в байтах (включая 8 байт заголовка) |

---

## Примеры запуска

Стандартная трассировка (параметры по умолчанию):

```bash
sudo python3 main.py vk.com
```

Быстрое сканирование (1 запрос на хоп, таймаут 1 секунда):

```bash
sudo python3 main.py google.com -n 1 -t 1
```

Ограничение глубины маршрута (максимум 10 шагов):

```bash
sudo python3 main.py yandex.ru -m 10
```

Изменённый размер пакета и интервал:

```bash
sudo python3 main.py fedoraproject.org -s 64 -i 2
```

## Особенности реализации

**Сетевой таймаут.** Ожидание ответа реализовано через неблокирующий системный вызов `select.select`, что предотвращает зависание потока при потере пакетов.

**Идентификация процесса.** Поле ID в заголовке ICMP заполняется на основе PID текущего процесса с наложением битовой маски `& 0xFFFF` для строгого соответствия 16-битному стандарту заголовка.
